memory

You recall information best in the same environment you learned it.

The encoding specificity principle suggests that memory retrieval is aided by cues present during the initial learning event.

Divers who learned lists of words underwater recalled them better while still underwater than on land. The surrounding physical environment serves as a retrieval cue for the information encoded within it. Your memory is not a clean file cabinet; it is a context-dependent system.

Where you learned a fact is part of the fact itself.

Where this comes from

Study
Godden and Baddeley, 1975, British Journal of Psychology
